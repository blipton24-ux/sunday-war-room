# ADR-007: Feature set

## Decision
All four candidate feature areas are in scope (delivered in phases, [ADR-009](ADR-009-Phasing.md)):

1. **Start/sit + matchup view**: weekly lineup help and a head-to-head matchup board with projections and live scores.
2. **Waivers + trade analyzer**: free-agent pickup suggestions and trade evaluation.
3. **AI assistant chat**: plain-English questions answered with your league's real data ([ADR-018](ADR-018-AI-Agent-With-RAG.md)).
4. **Live game-day dashboard**: scores updating during games, plus news and injury alerts (push notifications via the PWA, [ADR-010](ADR-010-PWA.md)).

## Why
Together they cover the whole weekly decision loop: set the lineup, improve the roster, follow the games, ask questions.
