# Round 2 tuning, by position

One page per position, generated by `python -m app.scripts.tune` as each stage finishes
([ADR-058](../../Decisions/ADR-058-P4-Round-2-One-Position-At-A-Time.md)): the sweep (every
setting alone), the tune (settings combined), and the one look at the check season. The pages hold
the numbers; what they mean and what was decided is written up in
[Model Experiments](../Model-Experiments.md).

Order: RB, WR, TE, QB, DEF, K. A page appears once its position has started.

- [RB](RB.md): sweep done; tune running
