# ML evaluation: the machine-learning model against 1.0.0

Generated by `python -m app.scripts.evaluate_ml`. Test seasons 2022-2025, walk-forward: each trained on 2016 to the season before, retrained before weeks 1, 5, 9, 13 with that season's earlier games added ([ADR-065](../Decisions/ADR-065-P4-Retrain-Every-Four-Weeks-In-Testing.md)). Settings are chosen inside the training seasons only. Startable: each week's top 15 QB and TE and top 36 RB and WR by season average, so both models are graded on the same players. Negative change = the ML model misses less; the result is "better" or "worse" only when the whole 95% interval (paired bootstrap over weeks) is on one side of zero. The ship rule ([ADR-061](../Decisions/ADR-061-P4-How-The-ML-Model-Is-Tested-And-Shipped.md)) also needs the 2026 weeks, looked at once in step 11. Kickers and defenses are not graded here (1.0.0 method until step 12). Rest-of-season projections still use the 1.0.0 method.
